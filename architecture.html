Little Joys — Creator Selection Pipeline

From raw brand data to 5 creator picks + what each should say

Raw Data (input) 4 CSV FILES

The brand's own data — ads, creators, posts, audience.

ads.csv creators.csv creator_posts.csv creator_audience.csv
Step 1 — Data Audit pandas

Shapes, missing values, duplicates, hidden likes, cross-file mismatches, manual label check.

intermediate/data_audit.md intermediate/label_check.csv
Step 2 — Ad Metrics pandas

ROAS, cost per purchase, hook rate, hold rate, CTR, conversion rate. Flag low-spend ads.

intermediate/ad_metrics.csv
Step 3 — Winning Patterns stats + bootstrap

Compare each ad label in-group vs out-group. Bootstrap CIs. Run for all / gummies / milk-mix. Child-led ads win (ROAS +1.02).

intermediate/winning_patterns.csv intermediate/winning_patterns_summary.md
Step 4 — Creator Profiles pandas

Median plays, reshare rate, child-on-camera %, language, risk flags. The pattern score is built from Step 3's winning_patterns.csv via a PATTERN_MAP (not hard-coded), so it stays in sync if Step 3 changes.

reads intermediate/winning_patterns.csv intermediate/creator_profiles.csv
Step 5 — Score, Pick 5, Stress Test weighted score

Weighted fit score (visible weights) minus risk penalty. Selection + variety rules live in pick_logic.py (unit-tested) and are used for both the main picks and every one of the 500 stress-test iterations.

intermediate/ranking.csv intermediate/stability.csv
Step 6 — Creator Briefs GROQ LLM

For each of the 5 picks, the LLM drafts: concept, opening line, talking points, claim to avoid, caption. Allowed claims are built at runtime from the ad data (claim_evidence.csv); a claim-checker flags any invented number or unsafe claim and logs it.

reads intermediate/ranking.csv + stability.csv + ad_metrics.csv intermediate/claim_evidence.csv outputs/briefs.md ai_log/decisions.md
Final Deliverables (output) FOR THE MANAGER

The answer and the briefs, written for Little Joys' marketing manager.

answer_for_manager.md briefs.md README.md NOTE.md
Pure data / stats (no AI) LLM step (Groq) — the only AI use Input / output boundary

Folder rule: every step writes its working files to intermediate/ and reads its inputs from there. Only final deliverables (outputs/briefs.md, outputs/answer_for_manager.md) go to outputs/. The AI correction log lives in ai_log/.
