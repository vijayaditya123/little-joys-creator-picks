## How to read this table

- **ROAS delta**: difference between this group's average ROAS and all other ads.
  Positive = this label type earns more per rupee spent.
- **Metrics won**: how many of the 5 metrics (ROAS, hook_rate, hold_rate, CTR,
  conversion_rate) this group clearly beats the rest on (bootstrap CI above out-group mean).
- **Signal**: strong = 3+ metrics, moderate = 2 metrics, weak = 0-1 metric.
- **n**: number of ads in this group. Patterns with n < 5 are excluded entirely.

## Known limits

- Patterns are correlational, not causal.
- Ad labels come from an AI system and may contain errors (see data_audit.md section 8).
- Some label groups have small n — treat those findings with extra caution.
- Spend varies widely; the minimum threshold (INR 5,000) filters the noisiest ads
  but does not eliminate all noise.
